# Orchestra Workspace Rule

Before planning or writing code in this workspace:
1. Read `AGENTS.md`, `docs/SPEC.md`, and `docs/TASKS.md`.
2. Respect the task tracks in `docs/TASKS.md` and update task checkboxes (`[ ]` -> `[/]` -> `[x]`) when working on a task.
3. Role kontrak saat ini: `superadmin`, `operator`, `pewawancara`, `peserta` (lihat `AGENTS.md` §3 dan `docs/SPEC.md` §2).
4. Never enable public registration; this is a closed recruitment system for BPS Kabupaten Jember (2027).
5. Keep database table/column contracts aligned with `docs/SPEC.md`.
